# 🌱 ColheitaSmart

### Dê o melhor destino para sua colheita.

Projeto desenvolvido para a **Global Solution 2026 — FIAP**, com foco em pequenos agricultores e na valorização da produção rural.

## 📌 Sobre o projeto

O ColheitaSmart é uma aplicação web voltada à organização e ao planejamento do pós-colheita.

A proposta é ajudar pequenos produtores a acompanhar seus alimentos, identificar o que precisa de atenção e organizar suas decisões de venda, contribuindo para reduzir desperdícios e valorizar cada colheita.

## 🎯 Objetivo

Facilitar a gestão do pós-colheita por meio de uma interface simples, apoiando o agricultor na organização dos lotes e no planejamento da comercialização.

## 👨‍🌾 Público-alvo

Pequenos agricultores e produtores rurais que desejam organizar sua produção e melhorar a gestão do pós-colheita.

## 🚧 Status do projeto

O projeto está em fase inicial de desenvolvimento. As páginas e os recursos serão ampliados nas próximas etapas.

Os dados apresentados na página inicial são ilustrativos e demonstram a proposta da aplicação.

## 🖥️ Páginas da aplicação

- **Início:** apresentação do projeto.
- **Minha Colheita:** área destinada ao acompanhamento dos lotes.
- **Tarefas:** área destinada à organização das ações do dia.
- **Vendas:** área destinada ao planejamento de vendas.
- **Carteira:** área destinada ao acompanhamento financeiro.
- **Sobre:** apresentação da proposta.
- **Integrantes:** apresentação da equipe.
- **FAQ:** perguntas frequentes.
- **Contato:** informações de contato.

> As páginas Sobre, Integrantes, FAQ, Contato e Carteira possuem uma estrutura inicial genérica.

## ⚙️ Como executar

É necessário ter **Node.js, npm e Git** instalados.

### 1. Clone o repositório

```bash
git clone https://github.com/AndreL050690/ColheitaSmart.git
```

### 2. Entre na pasta do projeto

```bash
cd ColheitaSmart
```

### 3. Instale as dependências

```bash
npm install
```

### 4. Inicie a aplicação

```bash
npm run dev
```

Abra no navegador o endereço informado no terminal.

Para encerrar o servidor, pressione `Ctrl + C`.

## 🛠️ Outros comandos

- `npm run build`: verifica o TypeScript e gera a versão de produção.
- `npm run preview`: abre uma prévia local após gerar o build.
- `npm run lint`: executa a análise estática do código.

## 📁 Organização do código

- `src/assets/`: recursos visuais.
- `src/components/`: componentes da interface.
- `src/pages/`: páginas da aplicação.
- `src/App.tsx`: estrutura principal e rotas.
- `src/main.tsx`: ponto de entrada.
- `src/index.css`: estilos globais.
- `src/App.css`: estilos da aplicação.
